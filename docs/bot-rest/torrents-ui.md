# Панель `/torrents`

Модули: `bot/torrents_view.py` (чистый рендер), `bot/handlers/torrents_panel.py` (callback'и и сетевые вызовы), `bot/handlers/torrents.py` (приём `.torrent`/magnet).

- Иерархия `t_*` в одном сообщении (список -> карточка раздачи) по образцу `/guests` и `/swarm`, правка того же сообщения. Служба torrents живёт на одной ноде, `dst`-адресация не нужна. Одно право на панель — `list@torrents`.
- Хэш раздачи запрашивается явным флагом `with_hash` (не через `ActionParam`): нужен только экрану бота как стабильный идентификатор для callback_data. Служба понимает точный хэш как есть — без риска попасть по подстроке имени (`torrents/service.py::_select`).
- Кнопка «🧲 qBittorrent» (`t_app`) — единственный вход в карточку apps/qbittorrent (юнит `qbittorrent-nox`), без кнопок управления; отдельного права `qbittorrent@apps` не спрашивают.
- Пресеты лимита скорости (0 = без ограничения): потолок 5 МБ/с (`torrents/service.py::MAX_SPEED_LIMIT_MBPS`), канал слабый.
- Лампы статусов: сырые состояния qBittorrent; у «стоп»-группы два префикса (qBittorrent 5 переименовал `paused*` в `stopped*`); `metaDL` — «ожидание», не активная скачка; `stalledUP` — нормальное сидирование, а не проблема (живая находка владельца 2026-08-22: в одной группе с «ждёт» читалась как «что-то не так»).
- Порядок групп (решение владельца 2026-08-22): проблемные первыми, дальше по убыванию «активности», раздача без занятого слота последней; внутри группы новые сверху (`added_on`).
- Прогресс в строке — «луной», не процентом (решение владельца): компактнее, высвобождает ширину под имя; 0 и 100 — отдельные фазы, середина делится пополам на 33. Точный процент — на карточке. Луна стоит рядом с лампой через пробел (два круглых эмодзи подряд читаются как один).
- Ширина строки: точных метрик шрифта клиента нет (Android/iOS/desktop разные), поэтому категориальная оценка ширины символа (1.0 ≈ строчная латинская); кириллица идёт тем же правилом (`str.isupper/islower` unicode-aware). Бюджет откалиброван по примеру владельца «🔵 Marvels.Daredevil.S01.1080p.L.N.B.J — 100% · ↓0»; `SAFETY_MARGIN` 0.85 — запас на неточность (без запаса часть строк переносилась на реальном клиенте). Имя режется по ширине, а не по числу символов.
- Скорость в строке — по реально идущему направлению (скачка — download, раздача — upload); у остановленных/ошибочных 0 и не показывается.
