# Подписка Hiddify и веб-страница (57.10–57.13)

## Токен
`vpn/subscription.py` чистый (ни сети, ни БД). Токен не содержит chat_id и нигде не хранится: 4 байта «поколения» (unix-время последнего перевыпуска/отзыва VLESS-ключа устройства на любой ноде) + 20 байт `HMAC-SHA256(секрет, "chat_id\0label\0поколение")`, всё base64url (32 символа). Любая vpn-нода пересчитывает MAC по своим активным VLESS-ключам и находит владельца (`_sub_local`), общая БД не нужна. Токен старого поколения отвергается, если хоть одна нода знает более новое — так перевыпуск гасит утёкшую ссылку (`resolve_subscription`; недоступный сосед пропускается, а его последние данные берутся из `_sub_stale`: страна не должна пропадать из подписки на время сбоя). Поколение живёт в `vpn_peers.revoked_at` снятых строк (`_device_gen`), поэтому переживает переустановку ноды из бэкапа; выпуск новой страны ничего не меняет — ссылка на телефоне остаётся живой.
Секрет — `[vpn].sub_secret`, а если пуст, производная от `[swarm].token` (он один на весь рой и входит в бэкап identity, поэтому ссылки переживают переустановку).

## Сбор ответа
`sub_links` между нодами: если у устройства здесь есть VLESS — сервер, UUID, расход и лимит гостя за месяц, поколение токена и сведения о ноде для страницы (адрес выхода, здоровье, AmneziaWG). Второй заход (`_sub_device_info`): ноды без VLESS у устройства узнают его по подписи токена (chat_id/label приходят от ноды, где VLESS есть) и сообщат про AmneziaVPN — для старых устройств, у которых VLESS только в части стран. Соседние ноды кэшируются на минуту. Параллельная загрузка страницы не должна оставить старый «ключа нет» — кэш сбрасывается при выдаче.

## Страница
`render_page` — хаб устройства: статус «VPN включён?», Hiddify одной кнопкой, страны и остаток, AmneziaVPN. Русский, на «вы», без пола, всё инлайн, автоперехода в приложения нет. Форматы подписки (`?format=`): `vless` (base64-список vless://, по умолчанию), `plain`, `singbox` (JSON с несколькими outbound). Статус «включён» определяется по адресу запроса (`detect_status`): из awg-подсети своей ноды — AmneziaWG (трафик к собственному адресу не маскарадится), с публичного адреса своей ноды — VLESS, с адреса соседа — только страна; GeoIP нет. `/where` (57.12): страница спрашивает каждую ноду из браузера, CORS — только для страниц наших нод (CSP `connect-src`). `deep_link` без `#имени`: Hiddify показывает фрагмент без декодирования процентов, имя берёт из заголовка `profile-title` (base64; заголовки HTTP — latin-1). Отдельный профиль в Hiddify для подписки, чтобы не спутать с обычным.
`detect_platform`: android / ios (iPhone, iPad, iPod) / other; iPadOS в режиме «компьютер» — Macintosh → other (показываются обе кнопки).

## Выпуск AmneziaVPN со страницы (57.13)
POST `…/awg` (node, nonce, action), ответ — JSON только скрипту страницы: Origin/Referer того же хоста, одноразовый nonce (в ответе следующий, живёт долго — страница может лежать открытой), частота (не чаще раза в 5 с на устройство и страну, 20 в час на устройство, 120 в час на ноду; в памяти, без адресов). GET ничего не выпускает — предпросмотр ссылок и сканеры (без JS) ключей не создают. `action=issue` ключ не заменяет (есть — `exists`), замена только `action=reissue`. Ключ только в этом ответе, `no-store`. Параллельных разборов токена не больше N (каждый ходит к нодам).

## Сервер (`vpn/subweb.py`)
`/s/<токен>`, `/s/<токен>/where`, `/s/<токен>/awg`, `/sub/<токен>`; всё прочее и неизвестный/отозванный токен — голый 404 (снаружи не отличить), заголовок `Server` убран, IP не пишутся. Порт отдельный (не 443/8443 — там mtg и xray). TLS: есть сертификат и ключ — https, иначе http (`sub_allow_http`). Let's Encrypt на IP короткоживущий (~6 суток), продлевает внешний таймер `deploy/sub-cert.sh`; раз в `RELOAD_EVERY_S` проверяется mtime и сертификат перечитывается на том же SSLContext; появление сертификата у работавшего по http сервера пересоздаёт сайт с TLS.

## Ключ `vpn://` AmneziaVPN
`amnezia_key.py` (57.12). Формат из исходников amnezia-client (`importController.cpp`): `vpn://` + base64url без `=` от `qCompress(JSON)` (4 байта длины big-endian + zlib). Структура — как клиент строит при импорте `.conf` с AWG: контейнер `amnezia-awg`, в нём `awg.last_config` — строка с JSON (с исходным `.conf`) и `isThirdPartyConfig: true`. MTU по умолчанию 1280 (defaultMtu Android/iOS, клиент подставляет своё). Ключ содержит приватный ключ клиента — обращаться как с `.conf`.
