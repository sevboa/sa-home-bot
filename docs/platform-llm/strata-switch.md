# Маршрутизатор моделей Strata (`llm/strata_switch.py`)

## Зачем

На mycraft одна видеокарта, и Strata держит в памяти одну модель: сменить её можно только
перезапуском. Скрипт запуска (например `/models/sa-home/stand/iq3-on.sh`) сам останавливает
старую модель и выходит с кодом 0, когда новая готова отвечать; запуск длится 1–2 минуты.

Маршрутизатор (`python -m sa_home_bot.llm.strata_switch`, по умолчанию `127.0.0.1:8090`) стоит
перед Strata и делает поле `model` в запросе выбором модели: сам дёргает нужный скрипт запуска и
проксирует запрос в Strata (`http://127.0.0.1:8080`). Клиенты — шлюз devlab и Open WebUI; обе уже
присылают `Authorization` с ключом Strata, поэтому маршрутизатор пересылает заголовок как есть,
ключей не хранит и не логирует.

## Правило переключения

- `acquire(model)` для уже загруженной модели ничего не перезапускает.
- Смена модели идёт под блокировкой: сначала ждём, пока счётчик запросов в работе станет нулевым
  и с конца последнего запроса пройдёт `idle_s` (по умолчанию 300 с). Пока текущей моделью
  пользуются, другую не запускаем.
- Быстрый путь «модель уже загружена» работает только когда переключения нет. Иначе запрос к
  старой модели ждёт блокировку: скрипт запуска уже погасил Strata, и пропустить запрос к старой
  модели означало бы отдать ей битовый ответ об ошибке. Во время переключения все запросы ждут.
- Не дождались за `max_wait_s` (по умолчанию 1800 с) — `SwitchBusy`, клиенту 503.
- Код выхода скрипта не 0 — `current` сбрасывается, `LaunchFailed`, клиенту 502.
- `GET /v1/models` список моделей отдаёт по ключам `launchers` и в Strata не ходит: Open WebUI
  зовёт его при выборе модели в списке, переключение должно случаться только на настоящем запросе
  к чату.
- К запросу в Strata сессия создаётся с `UPSTREAM_TIMEOUT`: `total=None`, `sock_read=None`,
  `sock_connect=15` (`UPSTREAM_CONNECT_S`). Таймаута на чтение ответа нет намеренно: локальная
  модель без потока отвечает до 15 минут, а devlab ждёт 900 с; дефолтные 300 с aiohttp рвали
  такой ответ на середине.

## TOML

```toml
default = "iq3"
idle_s = 300.0
max_wait_s = 1800.0

[launchers]
iq3 = ["/models/sa-home/stand/iq3-on.sh"]
qw2 = ["/models/sa-home/stand/qw2-on.sh"]
```

`default` обязателен и должен быть среди `launchers` (иначе `UnknownModel` при загрузке конфига);
`idle_s` и `max_wait_s` необязательны.

## Запуск

```
python -m sa_home_bot.llm.strata_switch --config /etc/strata/switch.toml
```

Аргументы: `--config` (путь к TOML), `--host` (`127.0.0.1`), `--port` (`8090`),
`--upstream` (`http://127.0.0.1:8080`). При старте приложения маршрутизатор загружает `default`
(он же прогревает модель), дальше переключается по запросам.

## Коды ответов

| Код | Когда |
| --- | ----- |
| 400 | нет поля `model`, тело не JSON-объект, имя модели нет в `launchers` |
| 502 | скрипт запуска вернул не 0 (`LaunchFailed`) или Strata не ответила |
| 503 | модель занята и переключение невозможно (`SwitchBusy`), текст `модель занята, переключение невозможно` |
