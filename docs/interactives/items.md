# Сюжетные предметы (items.py, этап 49.3, 59.3, 59.6)

`ItemKind` — данные персонажа в коде: название, облик, черты. Экземпляр у гостя — таблица `items`
(`db/schema.sql`), создают его только сценарии, не модель.

## Облик

Облик держится, только если это проверенная строка в коде («Стенд предметов» 2026-10-01): архетип
`RADIO_ARCHETYPE` рисуется turbo без ламп 32 из 32 раз, а описанный словами в промпте сцены предмет сцена «съедает».
Поэтому предмет рисуется отдельно портретом (служба llm, `item_portrait`) и вставляется в сцены пикселями
(`generate_image` с `paste`). Вырезка хранится на ноде llm по ключу; нет вырезки (сменили диск, почистили каталог) —
следующий снимок нарисует портрет заново. Портрет рисуется до трёх попыток turbo плюс очередь GPU: 2026-10-02
портрет пришёл через 193 с, бот бросил его на 180 — таймаут увеличен.

Черты копятся по ходу сцены (`item_trait` Ведущего; молчит — следующая по лестнице на ключевом моменте). Рисуются
только прошедшие стенд 49.3.0 (`Trait.en` не пуст). Стенд 49.3.0: без веса черты не рисуются (1/21); вес 1.3 — черты
копятся видно, фон остаётся серым (вырезке важно), облик узнаваем (DINO к базе 0.70–0.96); 1.5 по одной черте рисует
явнее, но 5 таких черт дают один глаз во весь кадр. `Curse` — «уровень проклятия»: портрет перекрашивается img2img
(`model` + LoRA), гниль и свечение растут с числом черт. `drawn_key` — что видно на портрете: другое — новый портрет.
Новый передатчик после смены один на всех: обычный архетип без черт, зерно из стенда (`NEW_RADIO_SEED = 33`),
готовность вырезки — флаг `item_cut_ready:radio-new`. Крупный план предмета снимается на пустой столешнице: иначе
промптер нарисует второй, свой передатчик.

## Вещи этапа 59

Канареечные (`ItemKind.canary`): видны и действуют только гостям из канарейки. Черты у них свободные
(`free_traits`): Ведущий пишет приметы своими словами, в портрете они не участвуют. Тексты вещи (`where_card`,
`where_menu`, `card_caption`, `menu_caption`, `note_card`, `note_tool`…) у радио — умолчания; пустое поле вида
означает тексты радио. Вино (`wine`, 59.3): хмель по умолчанию 3 ч (`TIPSY_HOURS`), после распития селфи с бокалом;
старый фотоаппарат (`camera`, 59.6): снимки Альфреда крупнее прежних 64 px (`CAMERA_PHOTO_PX`), эффект без срока,
пока вещь не вернут. «Применение» (49.4): действие с `consumable` оставляет вещь `consumed` — из описи и мест она
пропадает, запись и журнал остаются; карточка остаётся подписью без кнопок. Архетипы новых вещей — строки по образцу
радио, не проверенные 32 из 32 (стенд 59.0 не прогонялся).

## Действия

`ItemAction` — данные вида: `name` (как зовёт тул `item_action`), `code` (callback-код; у радио `p`/`r` со старых
карточек), `when` (где вещь должна быть), `effect`/`arg` (обработчик в движке, `_ITEM_EFFECTS`), `form`/`confirm`,
`tool_ru`, `done`, `event`, `directive`, `pinned_locked` (в закреплённых чатах речь недоступна), `consumable`,
`snapshot` (селфи после действия). Особенные вещи — рычаги поместья: не передаются (`transferable=False`), действия
доступны всегда — кнопкой из `/items` или просьбой Альфреду. У «Проклятой радиостанции» действие ставит старую
станцию или убирает её: это и есть переключатель картавости. Кнопка несёт намерение («поставить»/«убрать»), а не
«переключить» — речь можно сменить и формой `swap_radio`. `UserEffect` — эффект гостя со сроком (`hours`, `ended`,
`item_type` для подстановки модели в `{note}`): пока действует, `text` уходит скрытой заметкой в system Альфреда на
каждый ход.

## Тулы

`manor_items` (49.3.6): особенные вещи поместья. Перечень — для самого Альфреда (собеседник его не видит), действие
с вещью — только по просьбе гостя и только формой с кнопками (пользователь 2026-10-02: «статичная опись в чате —
не то»). Ход на этом заканчивается молча: карточка придёт сама и станет ответом Альфреда (находка 2026-10-15: фраза
«сейчас подготовлю описание» ломала четвёртую стену). `item_action` (49.3.7): форма с кнопками из данных действия,
решает кнопка, а не модель. `find_kind` ищет вид по словам модели: точное имя — раньше узора, канареечные узкие
слова — первыми («корпус фотоаппарата» не должно уходить в радио по слову «корпус»); «прибор/шкала/корпус» — так
Альфред зовёт радиостанцию в сцене, без них крупный план шёл без радио. Просьба снять убранный экземпляр
(«проклятый», «со склада») даёт карточку вместо снимка: снимается только кабинет, в кадр шло новое радио (находка
2026-10-01, Альфред трижды пенял на плёнку).
