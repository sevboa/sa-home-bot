# Интерактивы (`src/sa_home_bot/bot/interactives/`)

Сюжетные сценки поверх обычного `/ai`: гость говорит с Альфредом, а сценой незаметно
управляет отдельный LLM-агент Ведущий. Гость не видит слов «игра», «квест», «локация».

| Документ | О чём |
|---|---|
| [architecture.md](architecture.md) | разбиение кода на модули, что сознательно не сделано |
| [overview.md](overview.md) | жизненный цикл хода, согласие, формы и живые кнопки, канарейка, карта этапов плана -> модули |
| [scenarios.md](scenarios.md) | `Scenario`, `Run`, хранение, Ведущий (director), режим act, радио и «Стук снизу» |
| [places-and-rooms.md](places-and-rooms.md) | где стоит Альфред, комнаты, временные комнаты, обыск, запрет чужого места |
| [catacombs.md](catacombs.md) | топология лабиринта, кадры, быстрые переходы |
| [items.md](items.md) | `ItemKind`, радио/вино/фотоаппарат, действия, эффекты, опись и карточки |
| [photos.md](photos.md) | конвейер снимка кабинета: канон для SD, свет и погода, сверка зрением, селфи, портрет |
| [concurrency.md](concurrency.md) | порядок записей и гонки |
| [findings-log.md](findings-log.md) | датированные живые находки и решения владельца |
| [debug-draw.md](debug-draw.md) | отладочный `/draw` и тулы `generate_image`/`find_image` |

Принцип: тексты сцен, промпты Ведущего/SD, callback-коды и формат `images.params` — персонажные
или протокольные данные, их не переписывают при рефакторинге.
