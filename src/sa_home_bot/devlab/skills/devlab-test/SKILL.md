# devlab-test: тесты на mycraft

Тесты гоняются на исполнителе devlab (mycraft) в контейнере. Локальный `pytest` нужен только для
быстрой проверки одного-двух затронутых файлов.

## Условия
- Установлен MCP `devlab` (инструменты `devlab_test`, `devlab_test_log`, `devlab_status`,
  `devlab_inbox`) и есть токен `~/.config/sa-home-bot/devlab-token`. Нет: `nodectl devlab connect`
  (он же ставит и обновляет этот скил).
- Проект заведён на хабе (`devlab_projects`).

## Шаги
1. Снимок рабочей копии: из каталога репозитория `nodectl devlab snapshot`.
   Команда собирает временный коммит от `HEAD` с незакоммиченными и новыми файлами (без
   игнорируемых), не трогает ветки, индекс, файлы и stash, пушит его на хаб в
   `test/<имя ноды>/<n>`. В stdout последней строкой печатается ref, например
   `test/alfred/1762000000-1a2b3c4`. Проект берётся из `project` в `.devlab.toml` корня, иначе из
   имени каталога; другое имя: `--project <имя>`. Репозиторий без коммитов снять нельзя.
2. Прогон: `devlab_test project=<проект> ref=<ref из шага 1> args=[...] wait=240`.
   - `args`: фильтр пути, `-k`, `-x`. Пусто: весь набор. Команда по умолчанию из `.devlab.toml`.
   - `wait` не больше 240. MCP-клиент Claude Code по HTTP обрывает вызов, который 5 минут не
     присылал ни ответа, ни progress (хаб progress не шлёт). Длиннее ждать через опрос (шаг 3).
     Предел можно поднять: переменная `CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT` (мс, `0` отключает) и
     `timeout` в настройке сервера; конфиги пользователя без его просьбы не менять.
   - Спящий mycraft хаб будит сам (до минуты на пробуждение входит в `wait`).
3. Не дождались (`result: null`): запомнить `job.id`. Опрашивать `devlab_status id=<id>` до
   `done`/`failed`/`stopped` с паузой (вызов `sleep 60` в Bash) или смотреть `devlab_inbox` на
   сообщение `test_done`. Повторный `devlab_test` ставит новое задание, не используй его для ожидания.
4. Разбор результата `result`:
   - `exit_code` (0 успех, 124 таймаут), `duration_s`;
   - `summary`: passed/failed/errors/skipped;
   - `failures`: упавшие тесты с короткой выдержкой ошибки (до 50);
   - `tail`: хвост вывода.
5. Нужно больше: `devlab_test_log id=<id>` отдаёт последние 64 КиБ полного лога;
   `file=junit.xml` — junit. Чинить по упавшим, затем снова с шага 1 (с `args` только упавших,
   полный набор в конце).

## Если хаб или mycraft недоступен
Ошибка подключения MCP, `nodectl devlab snapshot` не достучался, задание долго `queued` без
пробуждения mycraft или `failed` с причиной исполнителя: прогнать локально по правилам CLAUDE.md
проекта (сначала затронутые файлы, полный набор в конце, в worktree `PYTHONPATH=$PWD/src`; на alfred
тяжёлое запускать по одному). Скажи владельцу, что полный набор прогнан локально и почему.

## Приёмка результата агента
Результат агента devlab проверяется тем же вызовом с ref ветки агента:
`devlab_test project=<проект> ref=agent/<id> wait=240`, снимок не нужен.
